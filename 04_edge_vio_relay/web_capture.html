📷 OpenVPS — Pengambil Foto untuk Pemetaan

Ambil 10–20 foto ruangan/objek dari sudut berbeda (overlap 60–80%), lalu kirim ke server OpenVPS untuk dibuatkan peta 3D (Modul 02 COLMAP).

Ganti dengan alamat VPS setelah dideploy (lihat docs/deploy_to_vps.md). Untuk tes lokal, jalankan uvicorn server:app --host 0.0.0.0 --port 8000 lalu pakai http://localhost:8000.
